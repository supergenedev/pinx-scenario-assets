# pinx-scenario-assets

PinX 시나리오에서 링크(URL)로 불러 쓰는 이미지 창고입니다. GitHub Pages로 게시됩니다.

주소: `https://supergenedev.github.io/pinx-scenario-assets/<작품ID>/<분류>/<파일>`

## 규칙
1. **이미 플레이 중인 작품이 이 파일들을 링크로 씁니다. 파일을 지우거나 옮기거나 이름을 바꾸지 마세요.**
2. 덮어쓰지 않습니다. 바꿀 때는 새 이름(예: `_v2`)으로 추가하고 시나리오의 링크를 바꿉니다.
3. 전체연령가 이미지만 올립니다.
4. 작품 ID별 폴더(`16295/`)에 둡니다. 표시용 WebP를 쓰고 원본 PNG는 올리지 않습니다.
5. 비밀번호·토큰·개인정보가 들어간 파일은 올리지 않습니다.

용량이 1GB에 가까워지면 회사 저장소(S3 등)로 옮깁니다. 담당: Ivy (ivy@supergene.co)
